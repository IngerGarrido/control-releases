# Freelance (release público)

Distribución pública de Freelance. Para instalar:

1. Subí todo el contenido por FTP/cPanel a la raíz de tu dominio.
2. Abrí `https://tudominio.com/` → te lleva al instalador.
3. Completá el wizard (base de datos + usuario admin).
4. Listo. Las actualizaciones futuras se aplican desde Configuración → Actualizaciones del sistema.

Versión interna: `b8b554c`
